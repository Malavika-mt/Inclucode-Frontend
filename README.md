# IncluCode Frontend

IncluCode Frontend is the user-facing application for the IncluCode project, designed to create a more inclusive and accessible digital experience for neurodivergent users.

## Awards

This project received a Special Mention Award at both:

- IEEE Assistive Technology
- IncluCode

## Overview

The frontend is built using Dart and Flutter to provide a modern, responsive, and accessible user interface. It is paired with Firebase for background integration, including authentication, real-time data handling, and cloud-backed services.

## Tech Stack

- Flutter
- Dart
- Firebase

## Purpose

The application focuses on improving accessibility, usability, and support for neurodivergent users by combining clean UI design with robust backend services.

## Getting Started

1. Install Flutter and Dart.
2. Set up Firebase for your project.
3. Run the app using your preferred Flutter device or emulator.

## Project Status

This repository serves as the frontend component of the IncluCode solution, with Firebase-based backend integration supporting the app experience.
